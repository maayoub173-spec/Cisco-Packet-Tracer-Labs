
# Cisco Packet Tracer Labs

Welcome to my Cisco Packet Tracer Labs repository.

This repository contains a collection of networking labs and practical exercises developed using Cisco Packet Tracer.

## About This Repository

The purpose of this repository is to document my practical learning journey in computer networking, covering fundamental and advanced networking concepts.

## Topics Covered

- Basic Networking
- VLANs and Trunking
- Inter-VLAN Routing
- DHCP and DNS
- Static Routing
- Dynamic Routing
- OSPF
- Access Control Lists (ACLs)
- WAN and ISP Networks
- Network Security

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

## Repository Structure

Each lab is organized into its own directory and may include:

- Packet Tracer (.pkt) project files
- Network topology screenshots
- Configuration notes
- Lab objectives and testing results

## Author

Created and maintained as part of my networking practice and self-learning journey.
